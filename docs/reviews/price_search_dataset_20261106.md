## Swissgrid extension

The official [Swissgrid energy-statistics archive](https://www.swissgrid.ch/en/home/customers/topics/energy-data-ch.html)
provides the source workbooks. Their exact bytes, normalized tables, source
URLs, parser settings and SHA-256 checksums are retained in DuckDB snapshots.
The separate XLSX files are optional after import.

| Source year | Local delivery coverage | Native intervals | Missing imported values |
|---|---|---:|---:|
| 2024 | 1 January–31 December | 35,136 quarter-hours | 0 |
| 2025 | 1 January–31 December | 35,040 quarter-hours | 0 |
| 2026 | 1 January–30 September | 26,204 quarter-hours | 0 |

The new `swissgrid / energy_statistics / CH` dataset contains national
generation and consumption, end-user consumption, directional physical
exchanges with Italy, France, Germany and Austria, total imports/exports/transit,
and four secondary/tertiary control-energy price series. Physical flows and
commercial schedules are distinct source fields.

Normalization preserves native kWh values and also stores mean MW:
`MW = interval_kWh / (1000 × interval_hours)`. At 15 minutes the divisor is 250.
Net exports to a neighboring country equal the outgoing physical-flow leg minus
the incoming leg. Positive values indicate Swiss exports. Missing legs remain
missing; they are not zero filled.

The workbook timestamp convention changes across years. The 2024 source labels
interval **ends**; from 2025 the workbook notes explicitly describe interval
**starts**. The parser localizes each source clock in `Europe/Zurich`, resolves
the repeated autumn hour, then shifts end labels in UTC. All source years have
unique interval starts. The observed daily counts include three spring days
with 92 intervals and two autumn days with 100 intervals. Independent SQL checks
reconcile the eight directional border legs to total imports and exports within
`3.5e-12 MW` of floating point precision.

Swissgrid's publication is monthly and revised. Delivery-day physical flows
used to explain delivery-day auction prices are explicitly **retrospective**.
This is the user's authorized study assumption, rather than a reconstructed
historical information set. Previous-day forecast features are assumed usable
at every decision gate, as requested.

The separate Swissgrid commercial-schedule/NTC/spot-spread dataset currently
contains 2026. That optional block must retain its own coverage and matched
comparison; it must not shorten the full-history physical-flow arms implicitly.
The same-day Italy NORD–CH **DA spread also contains the Italian DA clearing
price itself**. Using that spread to explain DA is an outcome-derived feature,
in addition to its publication-timing limitation. Such an arm must carry this
label in results and cannot establish operational forecasting performance.

## Database-only preparation

`configs/research/price_search_inputs.yaml` declares seven input tables for
1 January 2024–31 August 2026:

| Table | Rows | Native data |
|---|---:|---|
| NORD DA, IDA1, IDA2 and IDA3 | 213,099 | Original hourly and quarter-hour auction products |
| NORD load/generation/solar/wind forecasts | 268,194 | Original hourly and quarter-hour forecast intervals |
| PSV gas | 974 | Daily index |
| RTE France balance and source components | 46,746 | Half-hour intervals |
| Swissgrid physical-flow and balance statistics | 93,500 | Quarter-hour intervals |
| Swissgrid commercial border context | 186,592 | Quarter-hour variables; 2026 coverage |
| BFE Swiss reservoir observations | 840 | Weekly regional/state variables |

These exports preserve source gaps and native product resolutions. Hourly
prices are not converted into observed quarter-hour prices. Models are grouped
by auction and native product resolution. The price export has no duplicate
`dataset, product_start` keys. Farm archive and local Open-Meteo sources are
explicitly excluded by the source configuration. Existing weather-based model
experiments remain comparison runs.

For this window, DA prices and NORD load forecasts cover all 93,500 quarter-hour
positions by native interval containment. Generation forecasts leave 288
quarter-hours uncovered, and solar and wind forecasts each leave 484 uncovered.
IDA1/2/3 leave 1,728/1,056/384 quarter-hour positions uncovered before auction
cancellation and eligibility rules are applied; the IDA3 comparison grid covers
12:00–24:00 local delivery time. These are catalog coverage counts, not invented
observations or automatic exclusions. None of the price or NORD forecast source
intervals overlap. The [coverage audit](../../outputs/price_feature_selection/source_coverage.json)
retains the counts for downstream preprocessing.

The extractor reads DuckDB once before parallel fitting. Its manifest records
every selected snapshot ID, raw and normalized source checksums, selected-row hashes,
native intervals, missingness, source configuration, code hash and data-library
versions. A pinned manifest reads the original immutable snapshots from
`api_records`, including after newer snapshots become current. Runtime database
paths, output paths and SQL thread counts are excluded from the scientific
selection hash.

From the repository root:

```bash
conda activate bess
python -m scripts.download_swissgrid_energy --database /path/to/market.duckdb
python -m scripts.build_price_search_inputs --database /path/to/market.duckdb
```

To reproduce the recorded source selection after moving the database:

```bash
python -m scripts.build_price_search_inputs \
  --database /new/path/market.duckdb \
  --output outputs/price_feature_selection/reproduced_inputs \
  --pinned-manifest outputs/price_feature_selection/inputs/manifest.json
```

The model-search integration must record fixed random seeds, complete candidate
parameters, chronological split definitions, feature-block inclusion, training
row counts, selection losses and evaluation scores. Independent fits use explicit
worker limits and one estimator/BLAS thread per worker. Retrospective blocks
carry their availability label into the fit and score manifests. Prepared arrays
are derived artifacts and can be rebuilt from the catalog and these manifests.
